## 🛠️ How to Run

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Dev Server:**
   ```bash
   npm run dev
   ```

3. **Open in Browser:**
   http://localhost:5173

## 🎨 Design System

- **Fonts:** Geist (via Inter fallback)
- **Colors:** 
  - Primary: `oklch(0.6 0.22 220)` (Blue/Purple)
  - Backgrounds: Light (White), Dark (Black), Navy (Deep Blue)
